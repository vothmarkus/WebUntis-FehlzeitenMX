WebUntis-FehlzeitenMX

Erste Schritte
Melde dich unter Einstellungen bei WebUntis an und wähle das
Schuljahr. Hake die gewünschten Klassen für die Startseite und
für Meine Klassen an.

Anwesenheit ansehen
Die Startseite lädt ihre Klassen automatisch. Unter Meine Klassen
öffnet ein Klick die gewählte Klasse. Im Reiter Tagesmatrix kannst
du Klasse und Zeitraum frei wählen. Ein Klick auf einen Tag in
der Matrix zeigt die Details zur ausgewählten Person.

Abwesenheiten entschuldigen
Auf der Startseite öffnet ein Rechtsklick auf eine Fehlzeit oder
Verspätung die zugehörigen WebUntis-Einträge. Ein Klick auf
«Entschuldigung» öffnet den originalen WebUntis-Statusdialog
in einem Fenster, das sich an die Größe des Formulars anpasst.
Speichere im WebUntis-Dialog. Anschließend liest die App die
betroffene Klasse neu ein.

CSV für den Notenrechner
Unter Einstellungen → CSV-Download speicherst du die Namenslisten
der unter Meine Klassen angehakten Klassen in einer CSV-Datei.

Update
Beim ersten Öffnen der Einstellungen prüft die App GitHub.
Unter Update kannst du die Prüfung jederzeit wiederholen.
Die App zeigt die installierte und die verfügbare Version. Ist
ein Update verfügbar, lädt «Update auf … installieren» das Setup
von GitHub, prüft es und öffnet es. Das Setup schließt die App
beim Installieren. Der Download öffentlicher Releases ist frei.
